# МедВызов: регистрация заявок вызова СМП (клиентская часть)

Демо‑версия прототипа медицинской информационной системы.  
Клиентская часть MedCall.Registration.Client Desktop‑приложение (RAD Delphi + DevExpress).

## Описание проекта

«МедВызов» — демонстрационная версия клиентского приложения для регистрации заявок на вызов скорой медицинской помощи (СМП).  Проект демонстрирует:
* архитектуру RichUI десктоп‑приложения с разделением на слои;
* интеграцию с REST API серверной части;
* возможности DevExpress для построения сложного пользовательского интерфейса;
* подходы к структурированию логики и построению иерархии классов.

## Функциональные возможности

**Раздел «Заявки»:**
* отображение списка заявок в гриде с детализацией информации;
* просмотр, редактирование и удаление записей о вызовах СМП;
* фильтрация заявок по статусам;
* подсчёт количества заявок по фильтрам;
* отправка изменений на сервер через REST API.

**Раздел «Бригады»:**
* визуализация информации о бригадах СМП в виде грида с layout‑карточками;
* фильтрация бригад по статусам и подсчёт их количества;
* графическая визуализация работы бригады в течение дня в виде таймлайн.

## Технологии и стек

* **Платформа:** Win32;
* **Язык программирования:** RAD Delphi;
* **Компоненты UI:** DevExpress;
* **Формат данных:** JSON;
* **Интерфейс взаимодействия:** REST API (интеграция с серверной частью `МедВызов`).

## Запуск и настройка

### Предварительные требования

* Среда разработки **RAD Delphi 11+** с установленными компонентами **DevExpress**;
* запущенный сервер `МедВызов` (доступен по адресу `http://localhost:5285`).

### Локальный запуск

1. Соберите проект в RAD Delphi.
2. После сборки поместите следующие файлы в соответствующие каталоги:
   * файл `brigades.json` — в каталог `\data`;
   * PNG‑изображения из папки `TestData\MedBrigades\pict` — в каталог `data\pict`.
3. Запустите исполняемый файл приложения.
